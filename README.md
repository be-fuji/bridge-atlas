# 橋の構造図鑑

## 公開ページ（GitHub Pages）

- [橋の構造図鑑を開く](https://be-fuji.github.io/bridge-atlas/)
- [橋の分類と用語の地図を開く](https://be-fuji.github.io/bridge-atlas/bridge-theory.html)

橋の形式・部材を学ぶ3Dビューアと、断面・たわみ・エネルギー法の学習教材です。

index.html をブラウザーで開くと利用できます。分類と用語は bridge-theory.html にあります。

模型や計算例は学習用に簡略化しています。出典は教材中の公開資料リンクを参照してください。
